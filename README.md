# 🍷 Cellar Master (셀러 마스터)

**Cellar Master**는 와인 애호가들이 개인 와인 컬렉션을 관리하고 지인들에게 멋지게 공유할 수 있도록 설계된 고급 레스토랑 스타일의 웹 사이트입니다.
보안이 유지되는 나만의 관리자 대시보드에서 인벤토리를 손쉽게 관리할 수 있으며, 동적 테마가 적용된 퍼블릭 페이지를 통해 방문자들에게 세련된 와인 리스트를 제공합니다.

## ✨ 주요 기능

- **비공개 관리자 대시보드**: 내 셀러의 와인을 목적에 맞게 추가, 수정, 삭제할 수 있습니다.
- **간단한 구글 로그인 연동**: Supabase Auth를 이용하여 복잡한 비밀번호 없이 구글 계정으로 즉시 로그인할 수 있습니다.
- **다이내믹 퍼블릭 셀러 라우팅 (`/:username`)**: 유저의 고유 아이디를 활용해 나만의 URL 주소를 생성하여 지인들에게 공유할 수 있습니다.
- **프라이버시 우선 (Privacy First)**: 와인의 가격 정보는 방문자들이 보는 화면에서는 완전히 감춰지며, 오직 로그인한 셀러 관리자(주인)에게만 보입니다.
- **스마트 정렬 및 뷰 옵션**: 와인을 종류별(Category) 또는 국가/지역별(Region)로 그룹화할 수 있으며, 그 안에서 알파벳순이나 'Value(가격/가치 순)'으로 정렬할 수 있습니다.
- **우아한 테마 전환 시스템**: 사이트 방문자는 본인의 취향에 맞게 3가지 세련된 컬러 테마(Modern Minimalist, Classic Elegance, Dark Premium)와 2가지 화면 배치 방식(기본 카드형, 고급 레스토랑 메뉴판형)을 마음대로 전환해 가며 감상할 수 있습니다.
- **와인 종류 자동 컬러 매치**: 와인의 종류(레드, 화이트, 샴페인, 로제 등)에 맞춰 UI의 포인트 색상 배지가 자동으로 어울리게 조절됩니다.

## 🛠 사용 기술 스택
- 프론트엔드: **React + Vite**
- 라우팅: **React Router DOM**
- 아이콘 모음: **Lucide React**
- 백엔드 및 데이터베이스: **Supabase** (Auth + PostgreSQL)



### 이용 가이드
1. 브라우저에서 `http://localhost:5173/login` 으로 접속 후 **Continue with Google** 버튼을 눌러 로그인합니다.
2. 최초 로그인 시 자동으로 회원가입이 완료되며, `/admin` 대시보드 화면으로 이동합니다. 우측 하단의 [Add Wine] 버튼을 눌러 와인들을 등록해 보세요.
3. 등록을 마친 후 화면 우측 상단의 **[View My Cellar]** 버튼을 누르거나 `http://localhost:5173/본인의_유저아이디` 경로로 접속하시면 완성된 멋진 웹사이트를 보실 수 있습니다!
